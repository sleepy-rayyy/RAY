What is Cryptography?

Cryptography is the practice of protecting information by converting it into unreadable data.

It ensures that only authorized users with the correct key can understand the original message.

Symmetric Cryptography

  • Definition: Uses a single shared key to both encrypt and decrypt data.
  • Advantages: Fast and efficient for large amounts of data.
  • Disadvantages: Securely sharing the key can be difficult.
  • Examples: AES, DES.
  • Real-Life: Encrypting files before storing them.

Asymmetric Cryptography

  • Definition: Uses a mathematically linked key pair.
  • Keys: Public Key (encrypts) & Private Key (decrypts).
  • Advantages: Extremely secure, no need to share a secret key.
  • Disadvantages: Slower than symmetric encryption.
  • Examples: RSA, ECC.
  • Real-Life: Secure websites (HTTPS).
Public Key ➔ Encrypt ➔ 🔒 ➔ Private Key ➔ Decrypt

Hash Functions

  • Definition: Converts data of any size into a fixed-size string of characters.
  • One-Way: It is designed to be impossible to reverse or decrypt.
  • Examples: SHA-256, SHA-3.
  • Real-Life: Secure password storage and verifying file integrity.

Best Practices Checklist

  • ✅ Use strong, unique passwords
  • ✅ Enable Multi-Factor Authentication (MFA)
  • ✅ Keep software and systems updated
  • ✅ Never share private keys
  • ✅ Always use HTTPS websites
  • ✅ Backup encrypted data safely
